Proyek ini merupakan eksplorasi data menggunakan bahasa SQL di PostgreSQL berdasarkan data Austin Animal Center yang diperoleh dari kaggle. Tujuan utama dari eksplorasi ini adalah untuk menemukan pola, tren, dan insight dari data hewan yang masuk dan keluar shelter, termasuk jenis hewan, ras, kondisi saat masuk, serta outcome yang dicapai.

📁 Dataset
Dataset diambil dari Kaggle dan terdiri dari tiga file:
• Intakes.csv: Data saat hewan masuk ke shelter
• Outcomes.csv: Data hasil akhir
• Stray_Map.csv: Data lokasi penemuan hewan liar (tidak digunakan untuk analisis utama karena terbatas)

🧰 Tools yang Digunakan
• PostgreSQL (untuk query SQL dan transformasi data)
• Microsoft Word (untuk dokumentasi pembahasan eksplorasi)

🔍 Fokus Eksplorasi
• Kelompok Outcome terbanyak yang dialami hewan di shelter
• Distribusi outcome berdasarkan jenis hewan
• ras hewan yang paling sering masuk shelter
• 10 lokasi penemuan hewan terbanyak
• Persentase tiap jenis outcome
• Ras hewan dengan tingkat adopsi tertinggi
• Jumlah hewan liar (Stray dan Wildlife) yang outcome diadopsi
• Analisis durasi hewan berada di shelter (dari intake ke outcome)
• Perbandingan angka adopsi berdasarkan jenis kelamin hewan
